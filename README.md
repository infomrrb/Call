# 📞 কল লিস্ট জেনারেটর টেলিগ্রাম বট

একটি টেলিগ্রাম বট যা বাংলাদেশি মোবাইল নম্বর ইনপুট নিয়ে ১০০টি র্যান্ডম কল ডিটেইস তৈরি করে এবং CSV ফাইল হিসেবে ডাউনলোডের সুযোগ দেয়।

## ✨ ফিচারসমূহ
- ✅ ১১ ডিজিটের বাংলাদেশি নম্বর ভ্যালিডেশন
- ✅ ১০০টি র্যান্ডম কল ডেটা তৈরি (নম্বর, স্ট্যাটাস, তারিখ-সময়)
- ✅ মিসড, রিসিভ ও ডায়াল কলের পরিসংখ্যান
- ✅ প্রথম ২০টি ডেটা টেবিল আকারে দেখানো
- ✅ সম্পূর্ণ ডেটা CSV ফাইল হিসেবে ডাউনলোড
